# Cờ Caro Gia Đình

Game cờ caro X/O cho cả nhà, chơi ngay trên trình duyệt máy tính hoặc điện thoại.

- 3 liên tiếp (bàn 3×3) hoặc 5 liên tiếp (bàn 15×15)
- 2 người chung máy hoặc chơi với máy (Dễ / Khó), chọn bạn hay máy đi trước
- Quân X · O hoặc chấm màu đỏ / xanh
- Pháo hoa và nhạc mừng khi thắng
- 6 hình nền vui cho bé trai và bé gái
- Tiếng Việt / English / 中文

Chơi tại https://hplgames.github.io/co-caro/. Các trò chơi khác của cả nhà: https://hplgames.github.io/

Toàn bộ game nằm trong một file `index.html`, không cần cài đặt.
